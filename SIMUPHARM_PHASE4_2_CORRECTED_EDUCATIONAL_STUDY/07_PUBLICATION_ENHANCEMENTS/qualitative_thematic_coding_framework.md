# Qualitative Learning Evidence & Thematic Coding Framework
**Document ID:** P4.2-QUAL-CODEBOOK-2026-REV2.3 (ABSOLUTE FREEZE)  
**Methodology:** Structured thematic analysis with an inductively developed codebook, independent dual coding of a subset, comparison of coding decisions, and consensus resolution  

---

## 1. Structured Codebook Architecture
Student qualitative responses from `qualitative_feedback_form.md` are coded across three overarching thematic domains using a pre-defined codebook developed inductively from pilot responses:

### Theme 1: Fault Identification Strategies & Visual Affordances
- **Code 1.1 (Pressure Cues):** Citing the digital pressure gauge or pressure ripple as the primary diagnostic trigger.
- **Code 1.2 (Peak Morphology Cues):** Identifying split doublets or tailing as the primary discriminator for column bed voiding.
- **Code 1.3 (Baseline & Noise Cues):** Citing sharp negative baseline spikes as characteristic for pump cavitation.
- **Code 1.4 (Blank Run Comparison):** Using baseline subtraction or blank gradient runs to confirm mobile phase contamination.

### Theme 2: Persistent Misconceptions & Cognitive Confounds
- **Code 2.1 (Void vs Blockage Confound):** Assuming that column inlet voiding always causes severe system overpressure.
- **Code 2.2 (Solvent Mismatch vs Void Confusion):** Inability to distinguish between early-eluter solvent mismatch and universal band splitting.
- **Code 2.3 (Leak Location Ambiguity):** Confusion between pre-column leaks (causing retention elongation) and post-column leaks (causing peak area loss).

### Theme 3: Instructional Usability & Simulator Engagement
- **Code 3.1 (Exploratory Freedom):** Positive feedback regarding the ability to manipulate parameters without fear of damaging physical columns.
- **Code 3.2 (Visual Feedback Immediacy):** Praise for real-time chromatographic canvas rendering.
- **Code 3.3 (Interface Clarity / Navigation):** Specific suggestions regarding slider sensitivity or label clarity.

---

## 2. Dual Coding & Consensus Protocol
- **Dual Coding Proportion:** Two independent educational researchers independently code a 25% random sample of participant responses ($n \approx 6\text{--}7$ transcripts).
- **Inter-Coder Agreement:** Unweighted Cohen's Kappa ($\kappa$) is reported descriptively as an exploratory inter-coder agreement statistic across thematic tags. Agreement is not presented as a mathematical validation of qualitative truth or conceptual reality.
- **Consensus Resolution:** All discordant coding instances are discussed and resolved by consensus between the two coders before coding the remaining 75% of transcripts.
- **Data Status:** The framework is established a priori. Zero qualitative data or coder ratings have been fabricated.
