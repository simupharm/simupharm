# PHASE 5.2 GOVERNANCE CHARTER
## ADVERSARIAL INTEGRITY, CODE FREEZE & ETHICS REGISTER

### 1. GOVERNANCE PRINCIPLES
Phase 5.2 operates under strict regulatory and scientific governance designed to eliminate confirmation bias, prevent premature experimental execution, and enforce scientific conservatism:
1. **Adversarial Falsification Mandate:** The explicit purpose of this sprint is to attempt to DISPROVE Direction B. Confirmation seeking is classified as an audit failure.
2. **Absolute Code Freeze:** The SimuPharm engine code (`backend/science/`, `backend/simulations/`, etc.) is strictly locked. No equations, constants, heuristics, or fault models may be altered. All evaluations must be performed by executing the frozen code as-is.
3. **No Student or Human Recruitment:** Institutional ethics authorization remains pending under Phase 4.2.3. No participants, human subjects, student pilots, or qualitative surveys may be conducted.
4. **No Physical Laboratory Work:** Physical bench work is out of scope for this computational feasibility phase.
5. **No Data Fabrication or Hallucination:** All sensitivity numbers, convergence metrics, and statistical distributions must be generated from genuine computational execution. All literature citations must be verifiable.
6. **Conservative Language Enforcement:** The use of unscientific promotional terminology ("proves", "first-of-its-kind", "guaranteed", "perfect") is strictly prohibited. Claims must be framed in conservative scientific language ("indicates", "within the tested domain", "suggests", "requires experimental confirmation").

### 2. CORE ROLES & RESPONSIBILITIES
- **Adversarial Auditor:** Independent reviewer examining structural limitations, model artifacts, and physical plausibility.
- **Computational Statistician:** Oversees Sobol decomposition, Saltelli matrix generation, bootstrap confidence intervals, and convergence verification.
- **Chromatographic Domain Specialist:** Assesses whether the model reflects real analytical separation principles or implementation simplifications.
- **Hostile Reviewer Red Team:** Simulates aggressive peer review from journals such as *Journal of Chromatography A*, *Analytica Chimica Acta*, and *Journal of Pharmaceutical and Biomedical Analysis*.

---

### 3. GO / MODIFY / KILL DECISION FRAMEWORK
- **GREEN (GO):** Direction B satisfies all convergence, stability, interaction, plausibility, information-gain, and empirical anchoring criteria without disqualification under any of the 10 Kill Conditions.
- **YELLOW (MODIFY / REFRAME):** Global sensitivity analysis shows meaningful computational utility, but requires scope narrowing (e.g., reframing as a computational model applicability domain analysis or combining with physical DoE validation).
- **RED (KILL & PIVOT):** Direction B violates one or more Kill Conditions, is dominated by model artifacts, provides no added value over conventional DoE, or cannot be defended against hostile chromatography reviewers. Direct pivot to Direction G (*SoftwareX*) or Direction C (Multimodal QC) is immediately triggered.
